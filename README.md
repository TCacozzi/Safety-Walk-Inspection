# English Boost Learning App 📚

Uma aplicação interativa de aprendizado de inglês para crianças, especialmente desenvolvida com base no caderno de reforço "English Boost" do 3º ano.

## 🎯 Sobre

Este projeto contém um aplicativo React moderno que ensina inglês de forma divertida e interativa através de:

- ✨ 7 dias de aulas estruturadas
- 🎮 Exercícios interativos com 5 tipos diferentes
- 📊 Sistema de progresso com pontuação
- 🎨 Interface amigável e colorida
- 📱 Totalmente responsivo (mobile, tablet, desktop)

## 🚀 Quick Start

```bash
cd english-learning-app
npm install
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173) no navegador.

## 📚 Conteúdo

- **Dia 1:** Pronouns + AM/IS/ARE
- **Dia 2:** Present vs Past (IS/ARE × WAS/WERE)
- **Dia 3:** Helping Verbs (CAN/HAVE)
- **Dia 4:** MUST/MUSTN'T
- **Dia 5:** Suffix -ABLE
- **Dia 6:** Sentence Building
- **Dia 7:** Review + Mock Test

## 🎮 Recursos

- ✅ Multiple Choice Questions
- ✅ Fill-in-the-Blank Exercises
- ✅ True/False Questions
- ✅ Word Ordering
